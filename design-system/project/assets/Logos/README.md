Le mot `wubba` et son point, dans toutes ses encres. Tous les fichiers sont en tracés, sans texte vivant.

- `wubba-logo.svg` : mot `wb-ink` (#0E0F12), point `wb-signal` (#FF2A36). Sur fond clair.
- `wubba-logo-reversed.svg` : mot `wb-paper` (#F1F0EC), point `wb-signal`. Sur fond sombre.
- `wubba-logo-sur-signal.svg` : mot `wb-ink`, point `wb-paper`. Seulement sur un aplat `wb-signal`.
- `wubba-logo-mono-noir.svg` : une encre, #000000. Impression une couleur.
- `wubba-logo-mono-blanc.svg` : une encre, #FFFFFF. Gravure, tampon, fond photo sombre.
- `wubba-lockup-horizontal.svg` et `-reversed` : tuile + mot côte à côte, pour les en-têtes.
- `wubba-lockup-empile.svg` et `-reversed` : tuile au-dessus du mot, pour les formats carrés.
- `wubba-filigrane.svg` : une encre, #FFFFFF, à poser à 20–30 % d'opacité sur les aperçus vidéo.
