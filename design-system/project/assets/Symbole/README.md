Le w et son point, pour les petits formats.

- `wubba-symbole.svg` : w `wb-ink`, point `wb-signal`. Sur fond clair.
- `wubba-symbole-reversed.svg` : w `wb-paper`, point `wb-signal`. Sur fond sombre.
- `wubba-symbole-mono-noir.svg` (#000000) et `wubba-symbole-mono-blanc.svg` (#FFFFFF) : une encre.
- `wubba-symbole-petit.svg` : coupe pour 32 px et moins, point agrandi et trait épaissi. w `wb-ink`, point `wb-signal`.
